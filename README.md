# 🧠 AI Web App  
A multi-feature AI-powered web application built using **Python Flask**, providing a collection of smart tools such as summarization, sentiment analysis, content generation, speech processing, chatbot, grammar checking, and document conversion.This project aims to provide everyday AI utilities in a simple, fast, and user-friendly interface.
---

## 🚀 Features

### 🔹 **1. AI Summarizer**  
Summarizes long text into concise and meaningful summaries using advanced NLP models.

### 🔹 **2. Cover Page Generator**  
Automatically generates academic or professional cover pages with clean formatting.

### 🔹 **3. Sentiment Analysis**  
Analyzes any text and detects whether it is **Positive**, **Negative**, or **Neutral**.

### 🔹 **4. Text to Speech (TTS)**  
Converts written text into natural-sounding speech.

### 🔹 **5. PDF to DOC Converter**  
Converts PDF files into editable **.docx** documents.

### 🔹 **6. Speech to Text (STT)**  
Converts audio speech into accurate text using speech recognition models.

### 🔹 **7. Chatbot**  
A conversational AI chatbot capable of responding to queries and generating helpful responses.

### 🔹 **8. Grammar Checker**  
Detects grammatical issues, spelling mistakes, and improves writing clarity using AI models.

### 🔹 **9. Content Generator**  
Generates creative or professional content such as essays, ideas, paragraphs, or blog text.

---

## 🛠️ Tech Stack

### **Frontend**
- **HTML5**
- **CSS3**
- **JavaScript**
- **Bootstrap / TailwindCSS** 
- Responsive UI with card-based feature layout

### **Backend**
- **Python Flask** (main backend framework)
- **Flask Templates (Jinja2)** for rendering pages
- **REST APIs** for AI features
- Secure file handling for PDF, audio, and DOCX uploads

### **AI / ML Libraries Used**  
- **Transformers (HuggingFace)** – summarization, content generation  
- **Torch / TensorFlow** – deep learning model support  
- **NLTK / SpaCy** – text preprocessing, sentiment analysis  
- **SpeechRecognition** – speech-to-text  
- **gTTS / pyttsx3** – text-to-speech  
- **PyPDF2 / pdfplumber** – PDF handling  
- **python-docx** – DOCX generation  
- **Pydub / FFmpeg** – audio processing
